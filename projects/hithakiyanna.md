# HithaKiyanna

## Anonymous Support Messenger

HithaKiyanna is a mobile messaging project focused on simple anonymous conversations without requiring a traditional public profile.

### Highlights

- Anonymous sign-in workflow
- One-to-one chat interface
- Recent connection history
- Reconnect workflow
- Message notifications and vibration
- Mobile-first custom chat UI
- Supabase-backed conversations and messages
- Row Level Security design
- Automatic data-retention / cleanup planning

### Technology

Android / Capacitor · JavaScript · Supabase

### Project Type

Mobile messaging application project.

> Portfolio case study. Privacy and backend configuration are kept outside the public documentation.
